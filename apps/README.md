# Aplicaciones

Las aplicaciones se generan con las herramientas oficiales de cada framework ejecutando `scripts/bootstrap.sh` desde la raíz del repositorio.

| Carpeta | Aplicación | Herramienta |
|---|---|---|
| `api/` | Backend NestJS + Prisma | Nest CLI |
| `web/` | Frontend React + TypeScript | Vite |
| `mobile/` | App Flutter | Flutter CLI |
